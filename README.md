# Endurance Yearbook

달리고, 타고, 헤엄치고, 여행한 시간을 연도별로 정리하는 개인 멀티스포츠 연감입니다.

## 목표

- Strava에서 연간 활동 통계를 계산합니다.
- Google Docs의 공식 기록과 준비·회고 내용을 보완합니다.
- KakaoStory의 후기와 대표 이미지를 이벤트에 연결합니다.
- 완주뿐 아니라 DNF, 컷오프, 취소, 종목 변경도 기록합니다.
- 2025년과 2026년을 같은 기준으로 비교합니다.

## 데이터 원칙

- 공개 저장소에는 정제한 통계와 선별한 이미지만 포함합니다.
- Strava 전체 내보내기, GPX 원본, 로그인·팔로워 정보는 포함하지 않습니다.
- 공식 기록과 GPS 기록은 별도 필드로 유지합니다.
- 이미지의 위치정보와 타인의 개인정보를 확인한 뒤 공개합니다.

## 구조

```text
data/<year>/summary.json   연간·월별·종목별 통계
data/<year>/events.json    주요 대회와 도전
data/<year>/journeys.json  여러 날에 걸친 여행과 종주
assets/images/<year>/      공개 검토가 끝난 이미지
docs/                      데이터·디자인·검토 문서
scripts/                   통계 생성과 데이터 검증 도구
```

GitHub Actions 배포 설정은 별도로 추가할 예정입니다.
