# 콘텐츠와 데이터 구조

## 페이지 구성

사이트는 세 가지 화면으로 시작합니다.

1. 전체 연도 개요: 2025년과 2026년 비교
2. 연도 상세: 통계, 월별 리듬, 주요 이벤트, 대표 여정
3. 이벤트 상세: 공식 기록, Strava 기록, 검토 메모, 이미지

초기 구현은 한 페이지 안에서 연도를 전환하는 정적 사이트로 만들고, 데이터가 늘어나면 상세 경로를 분리합니다.

## 출처별 역할

| 출처 | 사용하는 정보 |
|---|---|
| Strava | 거리, 이동시간, 고도, 종목, 활동일, GPS 기반 기록 |
| Google Docs | 공식 기록, 구간 기록, 일정 변경, 준비와 결과 검토 |
| KakaoStory | 후기, 당시 감정, 현장 상황, 대표 이미지 |

## 충돌 처리

- 공식 기록과 Strava 이동시간은 하나로 합치지 않습니다.
- 대회 거리와 GPS 거리를 구분합니다.
- 제목만으로 완주 여부를 판단하지 않습니다.
- DNF, 컷오프, 취소, 종목 변경은 별도 상태로 저장합니다.
- 불확실한 내용은 `reviewStatus: needs-review`로 남깁니다.

## 이벤트 상태

- `finished`: 공식 완주
- `dnf`: 출발 후 미완주
- `cutoff`: 제한시간 또는 중간 컷오프
- `format-changed`: 듀애슬론 전환 등 종목 변경
- `cancelled`: 대회 취소
- `participated`: 공식 결과 확인 전 참가 기록

## 이미지 관리

이미지는 원본 수집과 공개 자산을 분리합니다.

```text
private/images/<event-id>/       원본 검토 공간, Git 제외
assets/images/<year>/<event-id>/ 공개 승인된 WebP
data/<year>/media.json           출처, 설명, 대체 텍스트, 공개 상태
```

공개 전 확인 항목:

- EXIF 위치정보 제거
- 타인 얼굴과 초상권
- 차량번호, 전화번호, 예약번호
- 집·직장·숙소의 정확한 위치
- 이미지 출처 URL과 촬영 시점

## 공개 단위

전체 활동을 이벤트 카드로 만들지 않습니다. 일상 운동은 통계에 포함하고, 아래 항목만 콘텐츠 카드로 선별합니다.

- 대회
- 장거리 도전
- 여러 날의 여행·종주
- 첫 경험 또는 개인 최고 기록
- 실패 이후 재도전처럼 연간 흐름을 설명하는 사건
