# 2026년 기록 검토

## 한 해의 성격

2026년은 2025년에 넓힌 종목들을 장거리 완주와 반복 도전으로 연결한 해다. 첫 풀마라톤, 산티아고 프랑스길, 표준거리 철인3종, 트레일 30km, 200km급 연속 라이딩을 거쳐 세 번째 풀마라톤으로 마무리했다.

## 핵심 통계

- 활동 878회, 활동일 280일
- 총거리 11,688.8km
- 이동시간 664.1시간
- 누적 상승고도 79,898m
- 사이클 10,572.3km
- 러닝 955.4km
- 수영 133.4km

## 대표 변화

1. 풀코스를 구미 4:51:59에서 대청호 4:39:37.06까지 단축했다.
2. 산티아고 프랑스길 823.49km를 13일간 완주했다.
3. 철인3종을 여러 지역에서 반복하며 수영과 전환 운영 경험을 쌓았다.
4. 첫 트레일 18km에서 30km까지 거리를 확장했다.
5. 문경새재 그란폰도에서 2025년 컷오프를 2026년 완주로 바꿨다.
6. 4일 연속 200km급 주행 중 DNF 이후에도 남은 구간을 이어갔다.

## 표시 시 주의할 기록

- 익산 아쿠아슬론은 러닝 기록이 있어도 공식 결과는 수영 컷오프다.
- 강에서 바다로 챌린지는 전체 여정의 완료와 안동 구간 DNF를 동시에 표시한다.
- 인천 마라톤 공식기록과 Strava 이동시간을 구분한다.
- 산티아고는 공식 순례길 거리와 실제 GPS 이동거리를 구분한다.

## 2025년과 비교

- 총거리는 약 870km 증가했다.
- 러닝은 약 298km, 수영은 약 32km 증가했다.
- 활동일은 272일에서 280일로 늘었다.
- 2025년은 종목 확장, 2026년은 장거리 완주와 재도전의 성격이 강하다.

## 추가 확인 과제

- 창원·황산·통영 철인3종 공식 총기록
- 홍천·삼척·충주·빙그레 그란폰도 공식 기록
- 인천 마라톤과 산티아고 대표 이미지 공개 검수
- 각 이벤트의 개별 KakaoStory 원문 URL 연결
